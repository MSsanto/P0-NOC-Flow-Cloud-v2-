# UX Documentation

Este diretório organiza fluxos, wireframes, estados, regras de interação, acessibilidade e screenshots do P0 — NOC Flow Cloud v2.

## Referência atual

- [UX e fluxos](../07-UX-FLOWS.md)

## Conteúdo esperado

Quando os artefatos forem produzidos pelo UX/UI Designer, este diretório poderá conter:

- fluxos de navegação;
- wireframes;
- especificações de componentes;
- estados de loading, erro, vazio e permissão;
- regras de interação;
- requisitos de acessibilidade;
- screenshots aprovadas para documentação e portfólio.

## Regra de manutenção

Mudanças visuais que alterem fluxo, comportamento ou critérios de aceite devem ser refletidas na documentação antes da homologação da release.
