# tests

Diretório para suites transversais e E2E. Testes específicos de módulo podem residir próximos ao código conforme convenção definida no scaffold.

## Suites planejadas

- E2E Playwright;
- security/cross-tenant;
- contract/OpenAPI;
- smoke pós-deploy;
- performance posteriormente.

Todos os dados devem ser sintéticos.
